The mental model

তিনটি জিনিস আলাদা রাখুন

P

Process হলো container

নিজস্ব virtual address space, open file এবং resource ধরে। একই process-এর thread-গুলো এগুলো share করে।

Chrome tab / VS Code / game—প্রতিটি এক বা একাধিক process হতে পারে।
T

Thread হলো execution unit

প্রতিটি thread-এর আলাদা stack, program counter ও CPU register state থাকে। Scheduler সাধারণত thread-ই schedule করে।

এক process-এর T1 ও T2 আলাদা core-এ সত্যিই parallel চলতে পারে।
C

Core আসল কাজটি করে

Nটি core একই মুহূর্তে সর্বোচ্চ Nটি thread execute করতে পারে। বাকিরা দ্রুত পালা বদল করে concurrency তৈরি করে।

৮০০ thread মানে ৮০০টি একসাথে চলছে না—বেশিরভাগ wait বা ready state-এ।
Concurrency ≠ Parallelism

দ্রুত পালা বদল, নাকি সত্যিই একই সময়ে?

Single-core-এ scheduler এত দ্রুত context switch করে যে সব app একসাথে চলছে মনে হয়। Multi-core-এ একাধিক thread একই মুহূর্তে execute করতে পারে।
