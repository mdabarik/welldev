Nginx বনাম Apache: একসাথে ১২টা request

    
প্রতিটা request-এ কাজ তিন ভাগে: একটু CPU কাজ (0.1s), তারপর app/database-এর জন্য অপেক্ষা (1s), তারপর আবার একটু CPU কাজ (0.1s)। Apache (prefork)-এ প্রতিটা request পুরো সময় একটা process আটকে রাখে — অপেক্ষার সময়ও। Nginx-এর worker অপেক্ষা করে বসে থাকে না; request-টা epoll-এ রেখে পরেরটা ধরে।

মনে রাখার জন্য

    

      
Headerকে পাঠায়কী বোঝায়

      
        
HostBrowserকোন ডোমেইন চাই। একই IP-তে অনেক সাইট থাকলে Nginx এটা দেখে server_name মেলায়।

        
Accept / Accept-EncodingBrowserকোন ধরনের ডেটা (JSON, ছবি) আর কোন compression (gzip, br) বুঝি।

        
Cookie / AuthorizationBrowserআমি কে — session বা JWT token। App-এর auth middleware এটা যাচাই করে।

        
X-Forwarded-For / X-Real-IPNginxApp শুধু Nginx-কে দেখে; আসল client IP জানাতে Nginx এগুলো যোগ করে।

        
Content-Type / Content-LengthServerBody কী ধরনের আর কত বাইট।

        
Cache-Control / ETagServerBrowser কতক্ষণ জমিয়ে রাখবে; পরে ETag দিয়ে জিজ্ঞেস করলে না বদলালে শুধু 304 আসে।

        
Set-CookieServerBrowser-এ নতুন cookie রাখতে বলে (যেমন login-এর পর session)।

      
    

    

      
Statusমানেসাধারণত কে দেয়

      
        
200 OKসফলApp বা Nginx (static)

        
301 / 302অন্য URL-এ যাও (redirect), যেমন http → httpsNginx বা app

        
304 Not Modifiedআপনার কাছে থাকা কপিটাই ঠিক আছে, body পাঠানো হলো নাNginx (ETag মিলে গেলে)

        
401 / 403কে আপনি জানি না / জানি, কিন্তু অনুমতি নেইApp-এর auth middleware

        
404 Not Foundএমন কিছু নেইNginx (ফাইল নেই) বা app (ডেটা নেই)

        
500App-এর ভেতরে bug / exceptionApp

        
502 / 504Nginx পেছনের app-এর কাছে পৌঁছাতে পারেনি / সময়মতো উত্তর পায়নিNginx

      
    

    

      
Nginx কী করে?
সামনে দাঁড়িয়ে থাকা দারোয়ান: TLS খোলে, static file নিজেই দেয়, বাকিটা proxy_pass দিয়ে app-এ পাঠায়, একাধিক app থাকলে load balance করে, gzip আর access log লেখে।

      
Apache কোথায় আলাদা?
পুরোনো, module-ভিত্তিক (.htaccess, mod_php)। prefork / worker MPM-এ প্রতি connection-এ process বা thread লাগে, তাই অনেক ধীর connection একসাথে এলে memory বেশি লাগে। নতুন event MPM অনেকটা Nginx-এর মতো।

      
App server কেন আলাদা?
Node, Spring, Django-তে আপনার business logic চলে। Nginx এটা সামনে থেকে আড়াল করে — app crash করলে Nginx অন্তত 502 দেখাতে পারে, আর একাধিক app instance-এ ভাগ করে দিতে পারে।

      
Keep-alive আর cache
প্রথম request-এ DNS, TCP, TLS-এ সময় যায়। একই connection খোলা থাকে (keep-alive), তাই পরের request এগুলো ছাড়াই যায়। Redis cache থাকলে database পর্যন্তই যেতে হয় না।
