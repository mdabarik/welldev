Project Overview

Project-টা কী? Architecture এক লাইনে বলো।
Career-সংক্রান্ত post শেয়ার করার community platform। Next.js + Tailwind frontend, Node + Express + TypeScript + Mongoose (MongoDB) REST API (/api/v1)।
কেন Next.js? React থেকে আলাদা কী?
File-based routing, SSR/SSG (SEO ভালো), middleware, built-in optimization। Post-ভিত্তিক public page-এর জন্য SEO গুরুত্বপূর্ণ।
Backend-এর structure কেমন?
Modular layered: Auth, Users, Posts, Categories module; প্রতিটিতে route → controller → service → model। সাথে AppError class আর catchAsync wrapper।

Auth & Security

Access token আর Refresh token কেন দুটো?
Access token ছোট মেয়াদের (মিনিট), চুরি গেলে ক্ষতি কম। Refresh token দীর্ঘমেয়াদি, শুধু নতুন access token নিতে ব্যবহার হয় এবং HttpOnly cookie-তে রাখা নিরাপদ।
Token কোথায় রাখো - localStorage না cookie?
localStorage-এ XSS-এ চুরি যায়। HttpOnly + Secure + SameSite cookie JS পড়তে পারে না; তবে CSRF ভাবতে হয় (SameSite/CSRF token)।
Role-based access (RBAC) কীভাবে বানিয়েছ?
JWT-তে role থাকে; backend middleware (auth('admin','editor')) role মিলিয়ে route আটকায়। Frontend-এ protected route শুধু UX, আসল check সবসময় server-এ।
Password কীভাবে store করো?
bcrypt দিয়ে hash + salt; plain text কখনো না। Encryption নয়, hashing - ফেরত আনা যায় না।
Validation কোথায় কীভাবে?
Zod/Joi schema দিয়ে server-এ validate; client-এ React Hook Form + Zod UX-এর জন্য। Client validation কখনোই যথেষ্ট না।

Frontend & Performance

State আর data fetching কীভাবে ম্যানেজ করো?
Redux Toolkit/RTK Query বা Axios interceptor (token refresh auto); server state cache হয়, loading/error সহজ হয়।
Optimistic UI কী? Like/comment-এ কীভাবে?
API উত্তরের আগেই UI আপডেট; fail করলে rollback। অনুভূত গতি বাড়ে।
Performance কীভাবে বাড়িয়েছ?
Lazy loading, code splitting, next/image, pagination, MongoDB index।

Database

MongoDB কেন, SQL না কেন?
Post/category নমনীয় document, schema প্রায়ই বদলায়। তবে strong relation/transaction লাগলে SQL ভালো - trade-off বলতে পারলেই হবে।
Post-এর সাথে author/category কীভাবে relate করেছ?
Mongoose ref + populate(); অথবা embed করা। Read-heavy হলে embed, বদলায় বেশি হলে reference।
