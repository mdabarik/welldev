Inventory Management System (.NET MVC)

ASP.NET Core MVC (.NET 9) দিয়ে product, category, supplier আর stock-in/stock-out ট্র্যাক করার web app।

GitHub

Project Overview

এই project-টা কী আর কেন বানিয়েছ?
Product, category, supplier-এর তথ্য রাখা আর stock-in / stock-out দিয়ে কতটুকু মজুত আছে তা ট্র্যাক করার ASP.NET Core MVC app। Pitch: কী সমস্যা, কে ব্যবহার করবে, তুমি কোন অংশ বানিয়েছ - ৩০ সেকেন্ডে বলার জন্য তৈরি থাকো।
MVC কীভাবে কাজ করে? তোমার project-এ কোথায় কী আছে?
  • Model - Product, Category, Supplier (Models/)
  • View - Razor page (Views/)
  • Controller - request ধরে Service ডাকে, View ফেরত দেয় (Controllers/)
Services layer কেন রেখেছ, Controller-এ logic দিলে কী সমস্যা?
Controller শুধু HTTP সামলাবে; business rule (যেমন stock কমানো) Services/-এ থাকলে test করা সহজ, reuse করা যায়, আর controller মোটা (fat) হয় না।

Database & EF Core

Data access কীভাবে করেছ? Code First আর Migration কী?
Entity class লিখে EF Core (DbContext) দিয়ে table বানানো = Code First। Model বদলালে Migrations/ schema-র version history রাখে, dotnet ef database update দিয়ে apply হয়।
Product ↔ Category ↔ Supplier relation কেমন?
Category-Product এক-থেকে-অনেক (1:N), Supplier-Product-ও সাধারণত 1:N। Foreign key + navigation property ব্যবহার হয়। (নিজের schema অনুযায়ী মিলিয়ে নাও।)
Stock কীভাবে হিসাব করো? দুইজন একসাথে stock-out করলে কী হবে?
Stock-in/out transaction আলাদা table-এ রেখে quantity আপডেট হয়। Race condition ঠেকাতে DB transaction আর concurrency token (RowVersion) বা atomic update দরকার।
N+1 problem আর IEnumerable বনাম IQueryable?
Loop-এর ভেতরে প্রতিবার query চালানো = N+1; সমাধান Include()। IQueryable DB-তে SQL হয়ে filter চালায়, IEnumerable memory-তে।

Security & Quality

Form-এ কোন কোন security ব্যবস্থা নিয়েছ?
  • CSRF - [ValidateAntiForgeryToken]
  • XSS - Razor default HTML-encode করে
  • SQL injection - EF Core parameterized query
  • Server-side validation (Data Annotations)
Authentication/Authorization কীভাবে? (যদি থাকে)
ASP.NET Core Identity বা cookie auth; role-based [Authorize(Roles="Admin")]। না থাকলে সৎভাবে বলো "এখনো যোগ করিনি, করলে এভাবে করতাম"।
Dependency Injection কী, কোথায় ব্যবহার করেছ?
Service/DbContext Program.cs-এ register করে constructor-এ inject করা হয়; coupling কমে, mock করে test করা যায়।
Project-টা scale করতে হলে কী করতে?
Pagination, caching, index, Repository/Clean Architecture, background job, Docker + CI/CD, আর PostgreSQL/SQL Server production DB।
