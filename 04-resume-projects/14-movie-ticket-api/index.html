Movie Ticket Booking API

Node.js + Express server, JWT Bearer token আর React client নিয়ে একটা পুরো project: GET, POST, PUT, PATCH, DELETE সব আছে। নিচে live demo চালিয়ে দেখো, তারপর animation-এ বোঝো কীভাবে চলে।

🎬 Live demo

এটা আসল React client। GitHub Pages-এ Node server চলে না, তাই এখানে browser-এর ভেতরেই একটা নকল API server চলছে। endpoint, validation আর status code আসল server-এর একদম একই (দুই জায়গাতেই একই ৫৩টা test পাশ করে)।

কী করবে: user@demo.com / user123 দিয়ে login → একটা movie → show → seat বাছো → Book → My bookings-এ গিয়ে bKash pay → Cancel। তারপর logout করে admin@demo.com / admin123 দিয়ে Admin tab-এ movie বানাও (POST), বদলাও (PUT/PATCH), মোছো (DELETE)। সবচেয়ে জরুরি: নিচের API console-এ প্রতিটা request-এর header, body আর status code দেখো।
নতুন tab-এ পুরো screen-এ খোলো ↗ Source code (GitHub) ↗ README ↗

নিজের machine-এ আসল server দিয়ে চালাতে:

cd server && npm install && npm start # Node API → http://localhost:4000/api cd client && npm install && npm run dev # React → http://localhost:5173
