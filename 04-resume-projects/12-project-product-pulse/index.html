Client Server

Project Overview

Project-টা কী? কে কী করতে পারে?
  • User - product যোগ, upvote/downvote (নিজের product-এ নয়), review, report, Stripe subscribe
  • Moderator - report/pending product approve বা reject
  • Admin - user role বদলানো, statistics, coupon তৈরি
Tech stack আর কেন?
React + Vite + Tailwind (client, Firebase hosting), Node/Express + MongoDB (server, Vercel), Firebase Auth, Stripe। Vite = দ্রুত dev build।

Auth & Security

Firebase Auth আর নিজের JWT - কীভাবে একসাথে কাজ করে?
Firebase দিয়ে login/Google sign-in; তারপর server নিজের JWT ইস্যু করে বা Firebase ID token verify করে। প্রতিটি protected API-তে verifyToken + verifyAdmin/Moderator middleware।
কেউ সরাসরি API ডাকলে admin route বাঁচবে কীভাবে?
UI লুকালে যথেষ্ট না; server-এ token verify করে DB থেকে role চেক করতে হয়।
নিজের product-এ vote ঠেকাও কীভাবে? একজন দুইবার vote?
Server-এ owner email মিলিয়ে reject; vote collection-এ (user, product) unique বা product-এ voter array + একবার-চেক। শুধু frontend-এ আটকালে হবে না।
Secret/API key কোথায় রাখো?
.env-এ (git-এ commit না, .env-example দাও); Stripe secret কখনো client-এ না।

Payments & Features

Stripe payment flow কেমন?
Client → server PaymentIntent বানায় (amount server ঠিক করে) → clientSecret ফেরত → Stripe Elements দিয়ে confirm → সফল হলে server-এ user-কে subscriber mark। ভালো practice: Stripe webhook দিয়ে নিশ্চিত করা।
Coupon কীভাবে কাজ করে?
Admin code, discount আর expiry বানায়; checkout-এ server validate করে amount কমায় - client-এর পাঠানো দাম বিশ্বাস করা যায় না।
Search, pagination আর trending কীভাবে?
MongoDB regex/text index দিয়ে tag/name search, skip/limit pagination, vote count দিয়ে sort।
React-এ data fetching কী দিয়ে? Caching?
TanStack Query + Axios (interceptor-এ token); cache, refetch, loading state অটো। Mutation-এর পর invalidateQueries।

Deployment & Improvement

Deploy কীভাবে করেছ? CORS?
Client Firebase Hosting, server Vercel। Server-এ শুধু client origin allow করে CORS বাঁধা।
কী উন্নত করতে চাও?
TypeScript, rate limiting, input validation (Zod), test, Stripe webhook, image upload CDN, role-ভিত্তিক audit log।
