    1Coin Change: সবচেয়ে কম coin-এ amount বানাওLeetCode 322 · DPFinal roundMedium

    কিছু coin-এর মান আর একটা amount দেওয়া। প্রতিটা coin যতবার খুশি নেওয়া যায়। সবচেয়ে কম কয়টা coin লাগবে? বানানো না গেলে -1।

    coins = [1, 2, 5], amount = 11 → 3 (5 + 5 + 1) coins = [2], amount = 3 → -1

    Greedy কেন ভুল

    Candidate-কে "greedy coin change" বলা হয়েছিল। বড় coin আগে নেওয়া (greedy) টাকার মতো coin-এ (1, 2, 5, 10) কাজ করে, কিন্তু সব সময় না। coins = [1, 3, 4], amount = 6: greedy নেয় 4 + 1 + 1 = ৩টি, অথচ 3 + 3 = ২টি। তাই interviewer-কে বলো: coin system standard হলে greedy চলে, নাহলে DP লাগবে। দুটোই লিখে রাখো।

    Idea (DP)

    dp[x] = x টাকা বানাতে সবচেয়ে কম coin। প্রতিটা coin c-র জন্য dp[x] = min(dp[x], dp[x - c] + 1)।

    C++ 
    int coinChange(vector<int>& coins, int amount) {
    const int INF = amount + 1;                 // এর চেয়ে বেশি coin কখনো লাগে না
    vector<int> dp(amount + 1, INF);
    dp[0] = 0;
    for (int x = 1; x <= amount; x++)
        for (int c : coins)
            if (c <= x) dp[x] = min(dp[x], dp[x - c] + 1);
    return dp[amount] == INF ? -1 : dp[amount];
}

// Greedy: শুধু standard coin (1, 2, 5, 10...) হলে ঠিক
int coinGreedy(vector<int> coins, int amount) {
    sort(coins.rbegin(), coins.rend());         // বড় থেকে ছোট
    int cnt = 0;
    for (int c : coins) { cnt += amount / c; amount %= c; }
    return amount == 0 ? cnt : -1;
}
    DP Time O(amount × n)Space O(amount)Greedy O(n log n)
    2Fibonacci series: শুধু দুটো variable দিয়েLeetCode 509 · IterationFinal roundEasy

    প্রথম nটা Fibonacci সংখ্যা print করো, অথবা F(n) return করো। F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2)।

    n = 7 → 0 1 1 2 3 5 8

    Idea

    Recursion লিখলে একই মান বারবার হিসাব হয়, time O(2ⁿ)। শুধু শেষ দুটো মান রাখলেই চলে: a আর b। প্রতি ধাপে b = a + b, a = পুরনো b। আগের round-এ ঠিক এটাই জিজ্ঞেস করা হয়েছিল ("only two variables"), তাই third variable ছাড়া লেখার trick-টাও জেনে রাখো।

    C++ 
    void printFib(int n) {
    long long a = 0, b = 1;
    for (int i = 0; i < n; i++) {
        cout << a << " ";
        b = a + b;      // নতুন মান
        a = b - a;      // পুরনো b (third variable ছাড়াই)
    }
}

int fib(int n) {
    int a = 0, b = 1;
    while (n--) { b = a + b; a = b - a; }
    return a;
}
    Time O(n)Space O(1)
    Review-এ প্রায়ই আসে: n বড় হলে int overflow হবে (F(47) আর int-এ ধরে না)। long long ব্যবহার করো, বা modulo চাইলে % 1e9+7।
    3দুটো ঘড়ির সময়ের পার্থক্য বের করোCustom · LeetCode 539-এর কাছাকাছি · String parsingFinal roundEasy

    দুটো সময় "HH:MM" (24-hour) দেওয়া: start আর end। মাঝে কত ঘণ্টা কত মিনিট গেছে? end যদি start-এর আগে হয়, ধরো মাঝরাত পেরিয়ে পরের দিন।

    start = "09:45", end = "17:10" → 7 hour 25 min start = "22:30", end = "01:15" → 2 hour 45 min (রাত পার হয়েছে)

    Idea

    দুটো সময়কেই মিনিটে বদলাও: h × 60 + m। পার্থক্য negative হলে ২৪ ঘণ্টা (1440 মিনিট) যোগ করো। শেষে আবার ঘণ্টা আর মিনিটে ভাগ করো। 12-hour format ("09:45 PM") দিলে আগে AM/PM বুঝে 24-hour-এ নিয়ে নাও; interviewer-কে format জিজ্ঞেস করো।

    C++ 
    int toMin(const string& t) {                   // "HH:MM" → মিনিট
    int h = stoi(t.substr(0, 2));
    int m = stoi(t.substr(3, 2));
    return h * 60 + m;
}

pair<int, int> timeDiff(const string& start, const string& end) {
    int d = toMin(end) - toMin(start);
    if (d < 0) d += 24 * 60;                    // মাঝরাত পার হয়েছে
    return {d / 60, d % 60};
}

// LeetCode 539: অনেকগুলো সময়ের মধ্যে সবচেয়ে কম পার্থক্য
int findMinDifference(vector<string>& times) {
    vector<int> m;
    for (auto& t : times) m.push_back(toMin(t));
    sort(m.begin(), m.end());
    int best = 1440 - m.back() + m[0];         // শেষ থেকে ঘুরে প্রথমে
    for (int i = 1; i < (int)m.size(); i++) best = min(best, m[i] - m[i - 1]);
    return best;
}
    Time O(1)539: O(n log n)
    Edge case: start আর end একই হলে উত্তর 0 নাকি 24 ঘণ্টা? এটা আগে জিজ্ঞেস করো। এমন প্রশ্ন করাটাই review-এ ভালো নম্বর দেয়।
    4Linked list-এ cycle আছে কিনা বের করোLeetCode 141 · Fast & slow pointerFinal roundEasy

    একটা linked list-এর head দেওয়া। কোনো node-এর next যদি আগের কোনো node-এ ফিরে যায়, তাহলে cycle আছে। true / false return করো।

    3 → 2 → 0 → -4 ─┐ ↑ │ → true └───────────┘

    Idea (Floyd's tortoise & hare)

    দুটো pointer: slow এক ঘর যায়, fast দুই ঘর। Cycle না থাকলে fast শেষে nullptr-এ পৌঁছায়। Cycle থাকলে fast ঘুরে এসে একসময় slow-কে ধরে ফেলে, যেমন দৌড়ের মাঠে দ্রুত দৌড়বিদ ধীরজনকে এক চক্কর পেছন থেকে ধরে।

    C++ 
    struct ListNode { int val; ListNode* next; };

bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;          // দেখা হয়ে গেছে
    }
    return false;                               // fast শেষে পৌঁছেছে
}
    Time O(n)Space O(1)
    Follow-up (LeetCode 142): cycle কোথা থেকে শুরু? দেখা হওয়ার পর একটা pointer head-এ রাখো, দুটোকেই এক ঘর করে চালাও, যেখানে মিলবে সেটাই শুরু। আরেকটা সহজ উপায়: unordered_set<ListNode*>-এ visited রাখা, কিন্তু তাতে O(n) space লাগে।
    5Stack ব্যবহার করে string উল্টাওStack · LIFOFinal roundEasy

    একটা string দেওয়া, stack দিয়ে উল্টো করে দাও।

    "WellDev" → "veDlleW"

    Idea

    Stack-এ যা শেষে ঢোকে, তা আগে বের হয় (LIFO)। তাই সব character push করে তারপর pop করলে উল্টো ক্রম পাওয়া যায়।

    C++ 
    string reverseWithStack(const string& s) {
    stack<char> st;
    for (char c : s) st.push(c);
    string out;
    while (!st.empty()) {
        out += st.top();
        st.pop();
    }
    return out;
}

// Follow-up: প্রতিটা word উল্টাও, word-এর ক্রম ঠিক রেখে
// "hello world" → "olleh dlrow"
string reverseEachWord(const string& s) {
    stack<char> st;
    string out;
    for (char c : s + " ") {
        if (c == ' ') {
            while (!st.empty()) { out += st.top(); st.pop(); }
            out += ' ';
        } else st.push(c);
    }
    out.pop_back();                             // শেষের বাড়তি space
    return out;
}
    Time O(n)Space O(n)
    Interviewer জিজ্ঞেস করতে পারেন stack ছাড়া কীভাবে: two pointer দিয়ে দুই মাথা থেকে swap (std::reverse), space O(1)। দুটোর পার্থক্য বলতে পারলে ভালো।
    6Map দিয়ে array-এর duplicate খুঁজে বের করোLeetCode 217 / 442 · Hash mapFinal roundEasy

    একটা array দেওয়া। যেসব সংখ্যা একাধিকবার এসেছে সেগুলো (আর কতবার এসেছে) বের করো।

    nums = [4, 3, 2, 7, 8, 2, 3, 1, 3] → 2 (2 বার), 3 (3 বার)

    Idea

    একবার পুরো array ঘুরে unordered_map-এ প্রতিটা সংখ্যার count রাখো। তারপর যাদের count > 1, তারাই duplicate। Nested loop দিলে O(n²), map দিলে O(n)।

    C++ 
    vector<pair<int, int>> findDuplicates(const vector<int>& nums) {
    unordered_map<int, int> freq;
    for (int x : nums) freq[x]++;

    vector<pair<int, int>> dup;
    for (auto& [val, cnt] : freq)
        if (cnt > 1) dup.push_back({val, cnt});
    return dup;
}

// LeetCode 217: duplicate আছে কি না
bool containsDuplicate(vector<int>& nums) {
    unordered_set<int> seen;
    for (int x : nums)
        if (!seen.insert(x).second) return true; // আগেই ছিল
    return false;
}
    Time O(n)Space O(n)
    Output sorted চাইলে map (ordered, O(n log n)) ব্যবহার করো। আর মান যদি 1..n-এর মধ্যে হয় (LeetCode 442), তাহলে index-এ চিহ্ন দিয়ে O(1) space-এও করা যায়।
    7Two SumLeetCode 1 · Hash mapআগের roundEasy

    Array থেকে এমন দুটো index বের করো যাদের মান যোগ করলে target হয়।

    nums = [2, 7, 11, 15], target = 9 → [0, 1]

    Idea

    প্রতিটা সংখ্যা x-এর জন্য দেখো target - x আগে দেখা হয়েছে কি না। আগে দেখা মানগুলো map-এ index সহ রাখো।

    C++ 
    vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> pos;                // মান → index
    for (int i = 0; i < (int)nums.size(); i++) {
        auto it = pos.find(target - nums[i]);
        if (it != pos.end()) return {it->second, i};
        pos[nums[i]] = i;
    }
    return {};
}
    Time O(n)Space O(n)
    8Move Zeroes: সব 0 শেষে পাঠাওLeetCode 283 · Two pointersআগের roundEasy

    সব 0 array-এর শেষে সরাও, বাকিদের ক্রম না বদলে। নতুন array বানানো যাবে না।

    [0, 1, 0, 3, 12] → [1, 3, 12, 0, 0]

    Idea

    w হলো পরের non-zero কোথায় বসবে। Non-zero পেলে nums[w]-এর সাথে swap করে w++।

    void moveZeroes(vector<int>& nums) {

    for (int i = 0; i < (int)nums.size(); i++)
        if (nums[i] != 0) swap(nums[w++], nums[i]);
}
    Time O(n)Space O(1)
    9Longest Palindrome: অক্ষর দিয়ে সবচেয়ে বড় palindromeLeetCode 409 · Countingআগের roundEasy

    একটা string-এর অক্ষরগুলো দিয়ে সবচেয়ে লম্বা কত দৈর্ঘ্যের palindrome বানানো যায়? (case-sensitive)

    "abccccdd" → 7 (যেমন "dccaccd")

    Idea

    প্রতিটা অক্ষরের জোড়া দুই পাশে বসানো যায়। তাই প্রতিটা count-এর জোড় অংশ যোগ করো। কোনো অক্ষর বিজোড়বার থাকলে একটাকে ঠিক মাঝখানে বসাও: +1।

    C++ 
    int longestPalindrome(string s) {
    unordered_map<char, int> cnt;
    for (char c : s) cnt[c]++;
    int len = 0;
    bool odd = false;
    for (auto& [c, k] : cnt) {
        len += k / 2 * 2;                       // জোড় অংশ
        if (k % 2) odd = true;
    }
    return len + (odd ? 1 : 0);                 // মাঝখানে একটা
}
    Time O(n)Space O(1) (৫২টা অক্ষর)
    10Group AnagramsLeetCode 49 · Hash map + sortআগের roundMedium

    একই অক্ষর দিয়ে বানানো শব্দগুলো (anagram) এক group-এ রাখো।

    ["eat","tea","tan","ate","nat","bat"] → [["eat","tea","ate"], ["tan","nat"], ["bat"]]

    Idea

    Anagram-দের অক্ষর sort করলে একই string হয় ("eat" → "aet")। এই sorted রূপটাই map-এর key।

    C++ 
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> groups;
    for (auto& w : strs) {
        string key = w;
        sort(key.begin(), key.end());
        groups[key].push_back(w);
    }
    vector<vector<string>> out;
    for (auto& [k, g] : groups) out.push_back(g);
    return out;
}
    Time O(n · k log k)Space O(n · k)
    113Sum: যোগফল 0 এমন সব tripletLeetCode 15 · Sort + two pointersআগের roundMedium

    Array-এর তিনটা ভিন্ন index-এর মান যোগ করে 0 হয় এমন সব আলাদা triplet বের করো (duplicate triplet নয়)।

    [-1, 0, 1, 2, -1, -4] → [[-1, -1, 2], [-1, 0, 1]]

    Idea

    Sort করো। প্রতিটা i fix করে বাকি অংশে two pointer (l, r) দিয়ে -nums[i] খোঁজো। একই মান পরপর এলে skip করো, তাতে duplicate আসে না।

    C++ 
    vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> res;
    int n = nums.size();
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;   // একই i বাদ
        int l = i + 1, r = n - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum < 0) l++;
            else if (sum > 0) r--;
            else {
                res.push_back({nums[i], nums[l], nums[r]});
                while (l < r && nums[l] == nums[l + 1]) l++;
                while (l < r && nums[r] == nums[r - 1]) r--;
                l++; r--;
            }
        }
    }
    return res;
}
    Time O(n²)Space O(1) (output বাদে)
    12Egg Drop: ২টা ডিম, n তলাLeetCode 1884 · Math / DPআগের roundMedium

    ২টা একই রকম ডিম আর n তলার বিল্ডিং। একটা তলা f আছে, তার উপর থেকে ফেললে ডিম ভাঙে, নিচ থেকে ভাঙে না। Worst case-এ সবচেয়ে কম কয়বার ফেলে f নিশ্চিত জানা যাবে?

    n = 2 → 2 n = 100 → 14

    Idea

    প্রথম ডিম m তলা থেকে ফেলি। ভাঙলে দ্বিতীয় ডিম নিচ থেকে একটা একটা করে, সর্বোচ্চ m - 1 বার। না ভাঙলে পরের বার m - 1 তলা উপরে যাই (কারণ একটা চেষ্টা খরচ হয়ে গেছে)। তাহলে m বারে ঢাকা যায় m + (m-1) + … + 1 = m(m+1)/2 তলা। সবচেয়ে ছোট m যেখানে m(m+1)/2 ≥ n, সেটাই উত্তর।

    C++ 
    int twoEggDrop(int n) {
    int m = 0, covered = 0;
    while (covered < n) {
        m++;
        covered += m;                           // 1 + 2 + … + m
    }
    return m;
}
    Time O(√n)Space O(1)
    k ডিমের সাধারণ রূপ (LeetCode 887) DP দিয়ে হয়: dp[t][k] = dp[t-1][k-1] + dp[t-1][k] + 1 = t বার ফেলে k ডিমে কত তলা ঢাকা যায়।
    13Largest Rectangle in HistogramLeetCode 84 · Monotonic stackআগের roundHard

    প্রতিটা bar-এর width 1, height দেওয়া। Histogram-এর ভেতরে সবচেয়ে বড় আয়তক্ষেত্রের area কত?

    heights = [2, 1, 5, 6, 2, 3] → 10 (5 আর 6 মিলে, height 5 × width 2)

    Idea

    প্রতিটা bar নিজের height নিয়ে বাঁয়ে-ডানে যতদূর যেতে পারে (যতক্ষণ ছোট bar না আসে), ততটা width। Stack-এ index রাখো, height বাড়তে থাকা ক্রমে। ছোট bar এলে stack-এর উপরের bar-এর ডানের সীমা পাওয়া গেল, আর stack-এ তার নিচের bar-টাই বাঁয়ের সীমা। শেষে 0 height-এর bar যোগ করলে সব bar হিসাবে আসে।

    C++ 
    int largestRectangleArea(vector<int>& heights) {
    heights.push_back(0);                       // শেষে সব pop করাতে
    stack<int> st;                              // index, height বাড়তি ক্রমে
    int best = 0;
    for (int i = 0; i < (int)heights.size(); i++) {
        while (!st.empty() && heights[st.top()] > heights[i]) {
            int h = heights[st.top()];
            st.pop();
            int left = st.empty() ? -1 : st.top();
            best = max(best, h * (i - left - 1));
        }
        st.push(i);
    }
    heights.pop_back();
    return best;
}
    Time O(n)Space O(n)
    শুরুতে brute force বলো (প্রতিটা bar থেকে দুই দিকে ছড়ানো, O(n²)), তারপর stack-এ optimize করো। এই ধাপে ধাপে ভাবাটাই interviewer দেখতে চান।
