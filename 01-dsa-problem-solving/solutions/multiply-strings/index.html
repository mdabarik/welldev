43. Multiply Strings

দুইটা বড় সংখ্যা string হিসেবে দেওয়া, integer-এ convert না করে গুণফল string-এ বের করতে হবে। ঠিক খাতায় যেভাবে গুণ করি: digit × digit, তারপর carry।

Medium NeetCode 150 LeetCode ↗

Problem

দুইটা non-negative integer num1 আর num2 string হিসেবে দেওয়া আছে। তাদের গুণফল string হিসেবে return করো। কোনো built-in BigInteger library ব্যবহার করা যাবে না, আর input সরাসরি integer-এ convert করা যাবে না (200 digit পর্যন্ত হতে পারে, long long-এও ধরবে না)।

Example 1num1 = "2", num2 = "3"
Output: "6"
Example 2num1 = "123", num2 = "456"
Output: "56088"

Idea

  • m digit × n digit-এর গুণফলে সর্বোচ্চ m + n digit হয় (যেমন 99 × 99 = 9801)। তাই nums নামে m + n size-এর একটা array নিই, সব 0।
  • num1[i] × num2[j]-এর ফল বসে nums[i + j + 1]-এ, আর carry যায় তার ঠিক বাঁয়ে nums[i + j]-এ। খাতায় গুণ করার সময় ডান দিক থেকে a-তম আর b-তম digit-এর গুণ যেমন (a + b)-তম column-এ বসে, এটা ঠিক সেই নিয়ম।
  • প্রতিবার sum = nums[i+j+1] + product: আগে যা জমা ছিল তার সাথে যোগ। sum % 10 সেখানেই থাকে, sum / 10 বাঁয়ে carry হয়। বাঁয়ের ঘরটা কিছুক্ষণের জন্য 9-এর বেশি হতে পারে, পরের গুণে সেটা আবার ঠিক হয়ে যায়।
  • শেষে nums-এর শুরুর 0 বাদ দিয়ে বাকি digit জুড়লেই উত্তর। কোনো input "0" হলে শুরুতেই "0" return।
