2013. Detect Squares

Point add করতে থাকো, আর query point দিলে বলো কয়টা axis-aligned square বানানো যায়। Query-কে এক corner ধরে diagonal-এর উল্টো corner খুঁজলেই বাকি দুই corner ঠিক হয়ে যায়।

Medium NeetCode 150 LeetCode ↗

Problem

একটা DetectSquares class বানাতে হবে:

  • add(point): plane-এ একটা point [x, y] যোগ করো। একই point একাধিকবার যোগ হতে পারে, প্রতিটা আলাদা point হিসেবে গোনা হয়।
  • count(point): query point-কে এক corner ধরে, আগে add করা point থেকে বাকি তিন corner বেছে কয়টা উপায়ে positive area-র axis-aligned square বানানো যায়, সেটা return করো।

Axis-aligned মানে square-এর বাহুগুলো x-axis আর y-axis-এর সাথে parallel (কাত করা square গোনা হবে না)।

Example (LeetCode)add([3,10]), add([11,2]), add([3,2])
count([11,10]) → 1
count([14,8])  → 0
add([11,2])
count([11,10]) → 2
কেন শেষে 2?(11,2) দুইবার add হয়েছে।
Square: (11,10), (3,10), (3,2), (11,2)
(11,2)-এর দুই copy থেকে
দুইটা আলাদা square হয়।

Idea

  • Query point q = (px, py)। Square-এর যে corner q-এর diagonal-এর উল্টো দিকে, ধরো d = (x, y), সেটা জানলে বাকি দুই corner আপনাআপনি ঠিক: (x, py) আর (px, y)।
  • d valid diagonal corner শুধু তখন, যখন |px − x| == |py − y| (দুই দিকে দূরত্ব সমান, তাই square) আর x != px (দূরত্ব 0 হলে area 0)।
  • Duplicate point আলাদা গুনতে হয়, তাই cnt map-এ point → কতবার add হয়েছে রাখি। একটা diagonal থেকে square-এর সংখ্যা cnt[d] × cnt[(x, py)] × cnt[(px, y)]। কোনো corner না থাকলে গুণফল 0।
  • count-এ map-এর প্রতিটা আলাদা point-কে d হিসেবে try করি আর সব গুণফল যোগ করি।
