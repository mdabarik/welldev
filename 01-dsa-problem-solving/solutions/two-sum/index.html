Two Sum

Array-র দুইটা সংখ্যা খুঁজতে হবে যাদের যোগফল target। Hash map দিয়ে এক pass-এই উত্তর: O(n) time।

Problem

একটা integer array nums আর একটা integer target দেওয়া আছে। এমন দুইটা আলাদা index return করো যাদের মান যোগ করলে target হয়। ঠিক একটাই উত্তর আছে, আর একই element দুইবার ব্যবহার করা যাবে না। Index যেকোনো order-এ return করা যায়।

Example 1nums = [2,7,11,15], target = 9
Output: [1,0]
2 + 7 = 9
Example 2nums = [3,2,4], target = 6
Output: [2,1]
2 + 4 = 6
Example 3nums = [3,3], target = 6
Output: [1,0]
3 + 3 = 6

এই code আগে second (বর্তমান index) push করে, তারপর first, তাই output-এ বড় index আগে আসে। LeetCode যেকোনো order accept করে।

Idea

  • Brute force-এ সব জোড়া check করলে O(n²)। প্রতিটা nums[i]-এর জন্য আসলে একটাই প্রশ্ন: target - nums[i] (complement) আগে দেখেছি কি না?
  • আগে দেখা সংখ্যাগুলো একটা unordered_map-এ রাখি: value → index। তাহলে "আগে দেখেছি কি না" check করা O(1)।
  • Complement map-এ না থাকলে বর্তমান সংখ্যাটা map-এ রাখি। থাকলে উত্তর পেয়ে গেছি: mp[complement] আর i।
  • আগে check, পরে insert: তাই একই element নিজের সাথে জোড়া হয় না। [3,3]-এ প্রথম 3 map-এ যায়, দ্বিতীয় 3 সেটাকে খুঁজে পায়।
