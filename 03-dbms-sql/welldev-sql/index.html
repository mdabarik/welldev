WellDev-এ জিজ্ঞেস করা SQL প্রশ্ন

চারটি প্রশ্ন, যেগুলো প্রায় প্রতিবার আসে। প্রতিটির জন্য problem statement, example table, solution আর PostgreSQL-এ চালানো আসল output দেওয়া আছে।

দ্রষ্টব্য: Query-গুলো PostgreSQL 18-এ সত্যিই চালিয়ে output নেওয়া হয়েছে। Order-এর তারিখ আজকের তারিখের সাপেক্ষে ধরা হয়েছে, তাই "আজ থেকে N দিন আগে" লেখা। প্রশ্ন ধরে ধরে খুলে দেখো।
4 questions
1N-তম সবচেয়ে বেশি salary (Nth highest salary)Ranking

Problem statement

employees table থেকে দ্বিতীয় সর্বোচ্চ (generally N-তম সর্বোচ্চ) salary বের করো। একই salary একাধিকজনের হলে সেটা একবারই গোনা হবে।

Example table

employees
idnamedept_idsalary
1Rahim190000
2Karim175000
3Sumi190000
4Nila260000
5Tanvir280000
6Mitu350000
7Arif350000

Solution

SQL 
-- ১) LIMIT / OFFSET: N = 2 হলে OFFSET 1 (অর্থাৎ N-1)
SELECT DISTINCT salary
FROM employees
ORDER BY salary DESC
LIMIT 1 OFFSET 1;

-- ২) DENSE_RANK: সবচেয়ে নিরাপদ, ties ঠিকমতো সামলায়
SELECT DISTINCT salary
FROM (
    SELECT salary, DENSE_RANK() OVER (ORDER BY salary DESC) AS rnk
    FROM employees
) t
WHERE rnk = 2;

Output (PostgreSQL 18-এ চালানো)

 salary 
--------
  80000
(1 row)
ব্যাখ্যা: salary গুলো বড় থেকে ছোট সাজালে হয় 90000, 90000, 80000, 75000, ... DISTINCT না দিলে OFFSET 1 আবার 90000-ই দিত (Rahim আর Sumi দুজনের salary সমান)। DISTINCT বা DENSE_RANK দুটোই ties সামলায়; RANK ব্যবহার করলে 90000-এর পর rank সরাসরি 3 হয়ে যায়, তাই 2 নম্বর rank-ই থাকে না। N জানা না থাকলে (parameter) OFFSET $1 - 1 লেখা যায়। কোনো department-এর ভেতরে N-তম বের করতে window-এ PARTITION BY dept_id বসাও।
2Duplicate row বের করোGROUP BY · HAVING

Problem statement

users table-এ কোন email একাধিকবার আছে আর কতবার আছে, তা দেখাও।

Example table

users
idnameemail
1Rahimr@x.com
2Karimk@x.com
3Rahim Br@x.com
4Sumis@x.com
5Karim Kk@x.com
6Rahim Cr@x.com

Solution

SQL 
SELECT email, COUNT(*) AS times
FROM users
GROUP BY email
HAVING COUNT(*) > 1;

Output (PostgreSQL 18-এ চালানো)

  email  | times 
---------+-------
 r@x.com |     3
 k@x.com |     2
(2 rows)
ব্যাখ্যা: GROUP BY email একই email-এর row গুলোকে এক group করে, COUNT(*) প্রতি group-এর row গুনে। group তৈরির পরে filter করতে হয় বলে শর্ত যায় HAVING-এ; WHERE-এ aggregate চলে না। COUNT(*)-এর ভেতরে অবশ্যই * বা column দিতে হয়, COUNT() error দেয়। পুরো row দেখতে চাইলে WHERE email IN (…এই query…) বা ROW_NUMBER() OVER (PARTITION BY email ORDER BY id) দিয়ে rn > 1 ধরো। ভবিষ্যতে ঠেকাতে UNIQUE (email) constraint বসাও।
3গত ৩০ দিনে যারা order করেনিLEFT JOIN · Anti join

Problem statement

customers table থেকে সেই customer-দের নাম দেখাও যারা গত ৩০ দিনে একটিও order করেনি (কখনো order না করলেও তারা তালিকায় থাকবে)।

Example table

customers
idname
1Rahim
2Karim
3Sumi
4Nila
orders
idcustomer_idorder_date
11আজ থেকে 5 দিন আগে
21আজ থেকে 40 দিন আগে
32আজ থেকে 45 দিন আগে
43আজ থেকে 10 দিন আগে

Solution

SQL 
SELECT c.name
FROM customers c
LEFT JOIN orders o
       ON c.id = o.customer_id
      AND o.order_date >= CURRENT_DATE - INTERVAL '30 days'
WHERE o.id IS NULL;

-- সমতুল্য: NOT EXISTS
SELECT c.name
FROM customers c
WHERE NOT EXISTS (
    SELECT 1 FROM orders o
    WHERE o.customer_id = c.id
      AND o.order_date >= CURRENT_DATE - INTERVAL '30 days'
);

Output (PostgreSQL 18-এ চালানো)

 name  
-------
 Karim
 Nila
(2 rows)
ব্যাখ্যা: Rahim-এর 5 দিন আগের আর Sumi-র 10 দিন আগের order আছে, তাই তারা বাদ। Karim-এর একমাত্র order 45 দিন আগের (৩০ দিনের বাইরে), আর Nila কখনো order করেনি, তাই দুজনেই আসে। ফাঁদ: তারিখের শর্তটা অবশ্যই ON-এ থাকবে। এটা WHERE-এ নিলে LEFT JOIN আসলে INNER JOIN হয়ে যায় আর Nila (order নেই) হারিয়ে যায়। o.id IS NULL মানে "মিলল না", এটাই anti-join।
4Department অনুযায়ী সর্বোচ্চ salaryCorrelated subquery

Problem statement

প্রতিটি department-এর সবচেয়ে বেশি salary পাওয়া employee-এর department-এর নাম, employee-এর নাম আর salary দেখাও।

Example table

employees
idnamedept_idsalary
1Rahim190000
2Karim175000
3Sumi190000
4Nila260000
5Tanvir280000
6Mitu350000
7Arif350000
departments
idname
1Engineering
2Sales
3HR

Solution

SQL 
SELECT d.name AS dept, e.name, e.salary
FROM employees e
JOIN departments d ON e.dept_id = d.id
WHERE e.salary = (
    SELECT MAX(salary)
    FROM employees
    WHERE dept_id = e.dept_id
)
ORDER BY d.name, e.name;

-- window function দিয়ে (বড় table-এ সাধারণত ভালো)
SELECT dept, name, salary
FROM (
    SELECT d.name AS dept, e.name, e.salary,
           RANK() OVER (PARTITION BY e.dept_id ORDER BY e.salary DESC) AS rnk
    FROM employees e
    JOIN departments d ON e.dept_id = d.id
) t
WHERE rnk = 1;

Output (PostgreSQL 18-এ চালানো)

    dept     |  name  | salary 
-------------+--------+--------
 Engineering | Rahim  |  90000
 Engineering | Sumi   |  90000
 HR          | Arif   |  50000
 HR          | Mitu   |  50000
 Sales       | Tanvir |  80000
(5 rows)
ব্যাখ্যা: ভেতরের subquery বাইরের row-এর dept_id ধরে ওই department-এর MAX(salary) বের করে (একে correlated subquery বলে), আর বাইরের query শুধু সেই salary-র employee রাখে। দুজনের salary সমান হলে (Engineering-এ Rahim ও Sumi) দুজনই আসে। শুধু একজন চাইলে ROW_NUMBER() ব্যবহার করে tie-break ঠিক করো। শুধু department-এর max salary চাইলে নাম ছাড়া GROUP BY dept_id আর MAX(salary)-ই যথেষ্ট।
